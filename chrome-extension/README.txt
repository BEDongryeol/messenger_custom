Dooray Skin (웹 Dooray 용) 설치법 - 크롬 / 엣지 / 웨일

1. 이 폴더를 지우지 않을 위치(예: 문서 폴더)에 그대로 두세요. 폴더를 지우면 기능이 꺼집니다.
2. 주소창에 입력 후 엔터
   - 크롬: chrome://extensions
   - 엣지: edge://extensions
   - 웨일: whale://extensions
3. 화면의 "개발자 모드" 스위치를 켭니다.
4. "압축해제된 확장 프로그램을 로드합니다" 클릭 → 이 폴더(DooraySkin-chrome-extension) 선택
5. Dooray 웹 메신저 탭을 새로고침(F5)

사용: 메신저 오른쪽 아이콘(돋보기, @, 클립, 링크) 아래 [Dooray Skin] 버튼 클릭 (또는 Alt+Shift+B)
     탭: 이 방(대화방 배경) / 전체(기본 배경, 설정 내보내기) / 테마(다크 모드, 테마 색)
제거: 2번 화면에서 Dooray Skin 의 "삭제"
업데이트: 새 버전이 나오면 패널에 알림이 뜹니다. 웹은 자동 설치가 안 되므로 새 zip 을 같은 폴더에 덮어쓰고, 2번 화면에서 Dooray Skin 의 새로고침(↻) 버튼 클릭 후 Dooray 탭 새로고침
